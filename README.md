# ILB 角色卡兼容（ILB Character Compatibility）

把**一张角色卡 + 它要用的 ILB 世界书 + 两者的关联**打成一个文件（`.ilbchar.json`），
换台机器、换个存档，导入后角色和书都还在、关联也还在。

- 依赖：[SillyTavern](https://github.com/SillyTavern/SillyTavern) 1.19.x 与
  [ILB（Independent Lorebook）](https://github.com/shayo-yoo/ILB) 0.28.0+（对外接口 1.4）
- 本扩展**不碰**酒馆原生角色卡管理：不加按钮、不改原生导入导出、不写 `data.extensions.world`
- 关联数据只存在 ILB 里，本扩展不另存副本

## 它解决什么问题

酒馆原生只能导出"角色卡"，ILB 只能导出"世界书"。一个角色的完整设定常常是
「这张卡 + 这两本书 + 这本书对他强制启用、那本强制停用」——这三样东西分开放，换设备就会散。

本扩展把三样打成一个包，并在导入时按真实 id 把关联重新接上。

## 安装

把整个目录放进：

```
SillyTavern/public/scripts/extensions/third-party/ILB-Character-Compatibility/
```

刷新酒馆，在「扩展设置」里会看到 **ILB 角色卡兼容** 卡片，点「打开」。

## 用法

三个页签：

| 页签 | 干什么 |
| --- | --- |
| 关联 | 看当前角色关联了哪些书、改策略（跟随书设置 / 强制启用 / 强制停用）、加/删关联 |
| 导入导出 | 勾选要带走的书 → 导出下载；或选一个 `.ilbchar.json` → 检查预览 → 导入 |
| 诊断 | ILB 是否连上、接口版本、当前角色、关联是否失效、上一轮实际启用了哪些书、最近 20 次导入导出 |

### 导出

1. 打开一张角色卡的聊天（群聊不能导出，见「已知限制」）
2. 「导入导出」→ 勾选要带走的书 → 「导出并下载」
3. 得到 `<角色名>-<日期>.ilbchar.json`

导出只读不写：不改角色卡、不改书、不改关联。

### 导入

1. 选文件 → 自动检查格式与版本，列出每本书会怎么处理（新建 / 用已有的 / 覆盖 / 复用同名书）
2. 有冲突的书会单独给下拉框，**默认不覆盖**
3. 确认后：**先导书，再导角色卡，最后用新 id 建关联**

书没导完就停，不会导入角色卡（角色卡导进去撤不回来）。结果会逐条列出成功/跳过/失败。

## 已知限制（v0.1.0）

- **群聊**：群聊里没有"当前角色"，关联页会提示先打开一张角色卡；群聊的关联投票由 ILB 自己按成员算。
- **只做 ILB 自己的包格式**：不做 PNG 内嵌、不做原生 `character_book` 转换（需求 §7 / §12 的后续阶段）。
- **角色卡删除不在这里做**：卡归酒馆管；本扩展只在探针里用接口清理测试数据。
- **手机真机未验证**：布局做了窄屏适配，但没有在手机上实测过。
- **导入的角色卡会不会重名**：不传 `preserved_name`，重名时酒馆自动加后缀，不会覆盖已有卡。
